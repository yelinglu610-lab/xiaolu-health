## 一、产品概述

小鹿是一个跑在 OpenClaw 上的个人 AI 健康助手，专注 Apple Watch 健康数据分析与生活辅助。

**核心价值：** 每天早 8 点准时发报告，用你能看懂的语言告诉你身体状态——不装医生，不说废话，像朋友一样聊。

**目标用户：** 戴 Apple Watch、关注健康数据、使用小红书 Hi 的用户。

---

## 二、核心功能

### 2.1 每日健康报告

**触发方式：** 心跳任务，每天 08:00-10:00 自动触发一次

**数据来源：** GitHub 私有数据仓（xiaolu-data），Apple Watch 导出数据

**报告内容：**

| 指标 | 说明 |
|------|------|
| HRV | 当日均值 + 与7日基线对比 |
| 静息心率 | 当日均值 + 趋势 |
| 步数 | 昨日步数 |
| 睡眠 | 时长（不戴表则标注未佩戴） |
| 节律评分 | S/A/B+/B/C 五档 |
| 黄金时段 | 基于 HRV 分布推算最佳专注时段 |
| 个性化建议 | 根据当日状态生成 1-2 条建议 |

**报告示例：**
```
🦌 早安！今天是 03/30 周一

━━━━━━━━━━━━━━━━━━
💓 HRV   43.9ms  ← 比基线高 +12ms 🟢
❤️  静息心率  74bpm  ← 正常范围
👟 步数   8,234步  ← 昨日
😴 睡眠   未佩戴
━━━━━━━━━━━━━━━━━━
节律评分：B+（80分）

今天状态不错，09:00-10:00 是你的黄金时段
适合安排需要专注的工作～
```

**推送渠道：** 小红书 Hi（hiredcity）

### 2.2 节律分析

基于历史 HRV 数据，分析用户每日时段规律：

| 时段 | HRV均值 | 状态 |
|------|---------|------|
| 09:00-10:00 | 47ms | 🟢 黄金时段 |
| 17:00-18:00 | 43ms | 🟢 次优 |
| 12:00-13:00 | 24ms | 🔴 低谷，避免重要决策 |
| 20:00-21:00 | 27ms | 🟡 恢复中 |

**节律评分标准：**

| 等级 | 分数 | 含义 |
|------|------|------|
| S | 90-100 | 最佳状态，全力冲 |
| A | 80-89 | 状态好，正常安排 |
| B+ | 75-79 | 不错，注意节奏 |
| B | 65-74 | 一般，避免过度消耗 |
| C | <65 | 注意休息恢复 |

**默认参数：** 上海 LuOne 凯德晶萃广场，1小时，3人间优先

### 2.4 待读清单

用户发链接（网页/小红书笔记/BP），小鹿自动处理：

1. 解析摘要（1-2句）
2. 询问目的：项目 / 赛道 / 感兴趣
3. 设定提醒时间（上午收→12点，下午收→16点）
4. 提醒时附带全网同赛道参考阅读 3 条

## 五、核心指标说明

### HRV（心率变异性）— 最重要指标

- 反映自主神经系统平衡状态
- 越高越好，但关键看**趋势**而非绝对值
- 低于7日基线 5ms+ → 可能疲劳/压力大
- 高于7日基线 5ms+ → 恢复良好，状态佳
- 用户基线：约 40-50ms，早高晚低为正常规律

### 静息心率

- 正常范围 60-100 bpm
- 长期偏高 → 关注睡眠和压力

## 六、隐私说明

- 健康数据存储在用户**自己的私有 GitHub 仓库**，小鹿不持有任何数据
- OpenClaw 仅在分析时读取，不做持久化存储
- 所有推送通过小红书 Hi，仅用户可见

## 七、已知限制

| 限制 | 说明 |
|------|------|
| 睡眠数据 | 用户不戴表睡觉，睡眠数据通常为空 |
| 数据更新 | 目前为手动导出，快捷指令自动化尚未配置 |
| HRV 基线 | 需积累30天+真实数据才准确 |
| CF Worker | 容器内网络限制，出站测试受阻 |
